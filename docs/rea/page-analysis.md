# 페이지 분석

표기: 확인 수준은 [overview](overview.md#2-확인-수준-정의) 정의를 따른다. URL의 `{userId}`·`{id}`는 가변 값이다. 접근성 트리와 요청 로그는 저장소에 포함하지 않았다.

## 0. 공통 셸

| 항목 | 내용 |
|---|---|
| 상단 헤더 | 카테고리 탭(홈·영화·시리즈·책·웹툰), 검색 입력(placeholder "콘텐츠, 인물, 컬렉션, 유저, 매거진 검색"), 알림 아이콘(로그인 시) |
| 하단 내비 | 비로그인 3탭 `홈 / 검색 / 로그인`. 로그인 5탭 `홈 / 검색 / 캘린더 / 피드 / 나의 왓챠` (`나의 왓챠` = `/users/{userId}`) |
| 푸터 | 약관·고객센터·사업자 정보·SNS 링크·언어 선택(한국어) |
| 오버레이 | 앱 설치 모달, 환영 광고 시트 (페이지 로드마다 노출, 시점 비결정적) |
| 이동 방식 | SPA 라우팅, 상세·하위 화면은 좌상단 뒤로가기 버튼 |

## 1. 홈 `/ko` — 실제 확인

위에서 아래로: 도메인 탭 → 히어로 카드("지금 가장 핫한 작품": 포스터·순위·평균 별점·방송사/장르·OTT 아이콘) → 바로가기 5개(매거진·이벤트·평가·취향분석·추천) → HOT 랭킹(순위 변동 up/down/same 표시, 비로그인은 "평균", 로그인은 "예상") → 인물 랭킹(좋아요 수 버튼) → 공개 예정작(보고싶어요 수, `227.9K` 형식) → 기타 가로 레일. 콘텐츠는 `page`·`size`로 나눠 추가 로딩한다. 비로그인 시 `취향분석`은 로그인으로, `평가`·`추천`은 로그인 후 접근된다.

## 2. 검색 `/ko/search` — 실제 확인

- 상단 검색 입력 + `취소` 버튼. 하단 내비는 유지된다.
- 빈 상태: "왓챠피디아 인기 검색어" 10개와 기준 시각("2026.11.10 09:30 기준").
- 입력 시 자동완성 API 호출, 확정하면 `?query=`로 결과 페이지로 이동한다.
- 결과 탭 5개: `콘텐츠 / 인물 / 컬렉션 / 유저 / 매거진` (`&category=contents|people|decks|users|articles`). 콘텐츠 탭은 영화·시리즈·책·웹툰 섹션으로 나뉘고 섹션마다 `더보기`가 있다.
- 결과 없음: 이미지와 "검색 결과가 없어요. 다른 검색어를 입력해보세요." 탭 5개는 그대로 유지된다.

## 3. 콘텐츠 상세 `/ko/contents/{id}` — 실제 확인

1. 히어로: 배경 이미지 위에 뒤로가기·공유, 제목·원제·`연도 · 장르 · 국가`·`상영시간 · 연령등급`·예매 순위/누적 관객
2. 별점 영역: 별 5개(미평가=회색). 평가 후 노란 별, `YYYY.MM.DD ·` + `수정`, `재감상 기록하기`, 코멘트 작성 유도 버튼
3. 액션 행: `보고싶어요 / 코멘트 / 보는 중 / 더보기` (아이콘 + 라벨 4등분)
4. 줄거리, 포스터
5. `출연/제작`(인물 가로 레일, 인물 상세 링크)
6. `코멘트 100+` + `더보기`. 비로그인은 카드가 블러 처리되고 "더 많은 코멘트를 보려면 로그인해 주세요!" + `로그인 하기`
7. `갤러리`, `동영상`, `이 작품이 담긴 컬렉션 84`(좋아요 수 표시)
8. 푸터

## 4. 코멘트

- **상세** `/ko/comments/{id}` — 실제 확인(비로그인 가능): 제목 "코멘트" → 작성자(아바타·닉네임·배지)·날짜(`YY.MM.DD`)·작품명 → 별점 칩(`★ 5.0`)과 포스터 썸네일 → 본문 → "OO님 외 N명이 좋아해요" + 👍 수·공유·`…` → 댓글 입력창(입력 전 `등록` 비활성) → "댓글 N개" + 정렬 `좋아요 순` → 빈 상태 "아직 댓글이 없어요 / 첫 댓글을 남겨보세요."
- **목록** `/ko/contents/{id}/comments` — 로그인 필요, 부분 확인: 로그인 시 `filter=all|friends`, `order=popular` 요청을 확인했다. 화면 구조는 분석하지 않았다.
- **작성** — 부분 확인: 웹에서 `코멘트` 버튼과 평가 후 유도 버튼 모두 에디터·이동·다이얼로그를 열지 않았다.

## 5. 평가 모아보기 `/ko/review` — 실제 확인 (로그인 필요)

상단 `평가` 제목과 `캘린더 가기` → 평가 수 큰 숫자와 격려 문구("이제 조금씩 취향의 윤곽이 드러납니다.") → 도메인 칩 `영화/시리즈/책/웹툰` → `랜덤 영화`(새로 고침) → 상태 칩 `보는 중`·`보고싶어요` → 미평가 작품 카드 스트림(포스터·제목·`국가 · 연도`, 카드 안에서 바로 별점).

## 6. 추천 `/ko/recommendations` — 실제 확인 (로그인 필요)

제목 `추천` → 도메인 칩 `영화/시리즈/책` → `나의 구독`·`태그` 필터와 스위치 "구독 중인 작품만 보기" → "{닉네임}님 인생의 작품이 될지도 모르는 작품들" 섹션 → 카드(`예상 4.6`, 제공 OTT, `더보기`) → 근거 문구 "재밌게 보신 '○○'와 비슷해요".

## 7. 캘린더 — 실제 확인 (로그인 필요)

**월간** `/ko/calendar/{userId}/{YYYY}/{M}`
- 헤더: 뒤로가기 · `26년 11월`(밑줄, 탭하면 월 선택 시트) · 이전/다음 달 화살표 · `이번 달`
- 월말결산 배너: "3개 평가 완료! 곧 월말결산을 볼 수 있어요."
- 도메인 칩 `전체 / 영화 / 시리즈 / 책` (선택 칩은 검정 채움, URL `?content_type=books`로 반영)
- 요일 헤더(일~토) + 날짜 격자: 평가한 작품의 **포스터 썸네일**이 칸 안에 놓이고 같은 날 여러 건이면 우상단에 개수 배지. 오늘은 강조 색, 미래 날짜는 흐리게. 각 칸은 `aria-label="YYYY-MM-DD"` 버튼이다.
- 우하단 `+` 플로팅 버튼 (동작은 미확인)

**월 선택 시트** — 제목 "캘린더 날짜 변경", 연도 + 12개월 격자, `완료`.

**일별 상세** `/ko/calendar/detail/{userId}/{YYYY}/{M}/{D}`: 뒤로가기 → `11월 8일` → "4 작품 감상했어요." → 행 목록(포스터·제목·`유형 · 연도`·★ 점수·`…` 메뉴) → 하단 고정 `작품 추가하기`(검정 전폭 버튼).

## 8. 프로필

**타인** `/ko/users/{id}` — 실제 확인: 아바타 · 닉네임 + 배지 · `팔로워 N`/`팔로잉 N`(각각 목록 링크) · 구분선 · 자기소개 · `팔로우`(검정 전폭 버튼) · 통계 3칸 `평가 / 코멘트 / 컬렉션` · `보관함`(영화·시리즈·책·웹툰 원형 아이콘 링크)

**본인** — 실제 확인: 위 구성에서 `팔로우` 대신 `프로필 수정`·`프로필 공유`·`…`. 추가로 `구독 중인 서비스`(OTT 등록 유도), **월 캘린더 미리보기 + `캘린더 전체 보기`**, 취향분석 요약(`#별점분포`, 빈 상태 "평가를 쌓으면 내 취향이 보여요" + `모든 분석 보기`), `좋아요`(좋아한 인물 N). 본인 프로필에는 계정 이메일이 표시된다.

## 9. 목록 화면 — 부분 확인

| 경로 | 제목 | 구성 |
|---|---|---|
| `/users/{id}/ratings` | 평가 | 도메인별 섹션과 개수(영화 9 / 시리즈 25 / 책 3 / 웹툰 0) |
| `/users/{id}/comments` | 코멘트 | 도메인 칩, 정렬 콤보박스(기본 `작성 순`) |
| `/users/{id}/decks` | 컬렉션 | 빈 상태 "아직 컬렉션이 없어요 / 첫 컬렉션을 만들어보세요." + `컬렉션 추가하기` |
| `/users/{id}/contents/{movies\|tv_seasons\|books\|webtoons}` | 보관함 | 도메인별 목록 (구조 미분석) |
| `/users/{id}/followers` | 팔로워 | 사용자 행마다 상태 버튼 |
| `/users/{id}/followings` | 팔로잉 중 | 사용자 행마다 상태 버튼 |
| `/users/{id}/likes?type=people` | 좋아한 인물 | 링크만 확인 |

## 10. 피드·알림 — 부분 확인

- **피드** `/ko/feed`: 제목 `피드` · 탭 `전체 / 팔로잉 / 내 활동` · `팔로우`(사용자 찾기) 버튼 · 항목 = 사용자 + 상대 시간("18시간 전") + 평가한 작품 카드(유형·제목·점수). 한 사용자의 연속 평가는 한 항목으로 묶인다. `내 활동` 탭 내용은 미확인.
- **알림** `/ko/notifications`: 제목 `알림` · 탭 `내 소식 / 이벤트` · 항목 "OO님 외 2명이 나를 팔로우해요." + 상대 시간("어제"). 미확인 알림 수는 `GET /api/notifications/unread`.

## 11. 취향분석 `/ko/users/{id}/analysis` — 실제 확인 (로그인 필요)

섹션: `평가수` · `별점 분포` · `영화 선호태그` · `시리즈 선호태그` · `영화 선호국가` · `영화 선호장르` · `영화 감상 시간`("18 시간") · `책 선호태그`. 데이터가 부족하면 섹션별 빈 상태 문구를, 있으면 재치 있는 제목 문구("인생은 역시 한 편의 드라마!")를 보여준다.

## 12. 로그인·회원가입 — 실제 확인

- `/ko/sign_in`: 로고 → 제목 `로그인` → `카카오 / Apple / Google / X / LINE / 이메일` 버튼 6개 → "아직 회원이 아니신가요? 회원가입"
- `/ko/sign_up`: "취향의 발견! 왓챠피디아에 오신 것을 환영해요." → `카카오로 회원가입` · `Apple로 회원가입` · `다른 방법으로 회원가입` → "이미 계정이 있으신가요? 로그인"
- 보호 경로(`/review`, `/recommendations`, `/contents/{id}/comments`)는 `sign_in?referer_url=%2Fko%2F...`로 이동시킨다.

## 13. 설정 — 미확인

프로필·헤더에서 진입 경로를 찾지 못해 분석하지 않았다.
